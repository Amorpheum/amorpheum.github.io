*Undergraduate course, SUTD*

## Description

A course on designing and building user interfaces, covering interaction design principles, prototyping, usability evaluation, and the implementation of interfaces in a modern front-end stack. Students move from low-fidelity sketches through interactive prototypes to a working, evaluated interface.
